Ledger Balance System - Money Pit

A simple browser app for tracking the balance from your salary, after deducting expenses and investment. A progress bar tracing a share of the amounts keyed. Also, included is a currency converter with live API to check the amount in different currency. This app build with plain HTML, JavaScript, styled using CSS and Bootstrap.

Features
Live budget table: enter your salary and expenses (Food, Rent, Others, Investment).
Percentage bars: each row in the table shows a coloured progress bar with the percentage of from the expenses and balance. Capped to 100% so it doesn't overflow.
Remaining / Overspent row: the last row shows the balance from your salary. If positive balance. the row shows Remaining, progress bar turns green. For Negative balance, label will show Overspent where the bar will turn red and show a negative percentage. 0 balance stays neutral.
Summary box: shows the net balance with its percentage of income. The box is green when positive balance and red when overspend.
Currency conversion: pick a currency from the dropdown (MYR or USD). Amounts already typed in are converted using exchange rates from the Frankfurter API. The currency label changes in the summary box and the amounts in the table. If the rates cannot be loaded (for example when offline), the app stays in MYR and an error alert is prompt.
Personalised greeting: first and last name are prompted before the page loads. This will be used in the greeting.
Responsive layout: using Bootstrap to align and adjust image and contents .
Animated touches: hovering over the "Money Pit" title turns it bigger.
